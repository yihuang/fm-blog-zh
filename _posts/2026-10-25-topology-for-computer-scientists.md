[上一篇]({% post_url 2026-10-19-liveness-and-fixed-points %})的结尾留了一句话：在无限轨迹构成的空间里，safety 是闭集，liveness 是稠密集。当时我把它当作一个漂亮的冷知识，写完就收起来了。

这篇文章要把这句话拆开。拆开之后你会发现，它几乎包含了拓扑学的全部动机——不是“橡皮泥几何”的那种动机，而是另一种：**一个只能做有限次观察的存在，究竟能知道什么。**

先问一个更像工程师会问的问题：两个东西“形状一样”，是什么意思？

直觉答案是“能连续地变形”。可是“连续”本身还需要定义。微积分的答案是 ε-δ：它很好用，但它要求你先有一个距离。拓扑学走得更远：它先问“你能观察到什么”，再让“连续”去适应观察。

这个顺序的颠倒，是理解拓扑学的钥匙。再往前一步：如果观察是第一性的，那么空间本身就应该由“观察的代数”来定义，而“点”只是这套代数的模型。这篇文章会走到这一步——前半程建立这套逻辑，后半程用它重新解释形状。

## 一、拓扑是一族“可确认的性质”

想象你在读一条无限长的 0/1 流：网络包、传感器读数、一条程序执行的轨迹。你没有全局视角，只能一位一位地看。

现在问：下面这些断言，哪些能在有限步内被你**确认**？

| 断言 | 能确认吗 | 为什么 |
|---|---|---|
| 第 3 位是 1 | 能 | 看到第 3 位就停 |
| 序列里出现过 1 | 能 | 一旦看到 1 就停 |
| 前 5 位全是 0 | 能 | 看 5 位 |
| 第 3 位是 1，且第 7 位是 0 | 能 | 看 7 位 |
| 序列里没有 1 | 不能 | 看多少位都只是“到现在还没有” |
| 这条序列等于某条特定的 σ | 不能 | 要比较无限多位 |

把“能被有限观察确认”的断言收集起来，记作 τ。它有几个显然的性质：

- **空断言**不需要观察就能确认（它什么都没说）；**整个空间**也不需要（它总是真的）。
- **合取**：两个能确认的断言，合起来也能确认——做两次观察。这就是有限交。
- **析取**：一族能确认的断言，只要其中一个被确认，“存在一个成立”就被确认了——这就是任意并。它不要求你事先知道是哪一个。

这组性质，就是**开集公理**。一个拓扑空间，就是“一个集合 + 一族被指定为开的子集”，满足：

```lean
-- mathlib 里的真实定义（省略命名空间前缀）
class TopologicalSpace (X : Type u) where
  IsOpen : Set X → Prop
  isOpen_univ : IsOpen univ
  isOpen_inter : ∀ s t, IsOpen s → IsOpen t → IsOpen (s ∩ t)
  isOpen_sUnion :
    ∀ S : Set (Set X), (∀ t ∈ S, IsOpen t) → IsOpen (⋃₀ S)
```

注意它**没有**说“补集也开”，也**没有**说“无限交也开”。

这两条缺口不是疏忽，而是“确认”这个动作本身的形状：

- **没有补集**：你能确认一个命题为真，不代表你能确认它为假。“序列里出现过 1”可以被确认，“序列里没有 1”不能。确认是单向的。
- **没有无限交**：确认两个断言只需两次观察；确认可数无穷多个断言，可能需要无穷多次观察。在 0/1 流上，把一条固定序列 σ 的前 n 位记作 σₙ，那么 ⋂ₙ [σₙ] 是单个点 {σ}——它要求比较无限多位，所以不是开集。

在 0/1 流上，开集长什么样？它们都是**有限前缀柱体**的并。一个柱体 [s] 是“所有以有限串 s 开头的序列”。它的并，就是“存在一个有限前缀，看到它就能下结论”的全体。

![开集就是有限前缀柱体的并]({{ '/images/topo-01-tree.png' | relative_url }})
{: .post-figure}

*图 1：0/1 流的观察树。每个节点是一个有限前缀；一个柱体 [s] 是 s 下面的整棵子树。开集是若干柱体的并。点 x = 0100… 落在 U 里，因为只看 3 位（010）就够了。*
{: .caption}

不同的拓扑，就是不同的“可观察性承诺”：

| 拓扑 | 开集是什么 | 观察读法 |
|---|---|---|
| 离散拓扑 | 所有子集 | 能直接看到点本身 |
| 平凡拓扑 | 只有 ∅ 和 X | 什么也观察不到 |
| Sierpiński 空间 | ∅、{1}、{0,1} | 一个 bit 的半可判定性 |
| 余有限拓扑 | 补集有限的集合 | 确认 = 排除有限多个反例 |
| Cantor 空间 | 柱体的并 | 只能看有限多位 |

同一批点，配上不同的拓扑，就是不同的“世界”：在离散世界里，任何性质都能被确认；在平凡世界里，什么都不能。**拓扑不是点的性质，是“观察能力”的性质。**

这不是一个比喻。Vickers 在《Topology via Logic》里把它做成了公理化的理论：一个拓扑系统由“点”“观察”“满足关系”组成，观察的集合构成一个框架，每个观察对应一个开集。开集就是“可被有限观察确认的断言”（finitely observable / affirmable property）。

下面用 Lean 把这几条钉死。先准备环境（后文所有代码都在同一个文件里）：

```lean
import Mathlib

open Set Filter
open scoped Topology
```

> 本文的 Lean 代码在 Lean 4.35.0-rc3 + mathlib v4.35.0 下编译通过。代码块里的 `example` 不产生输出——编译通过本身就是证明。

然后：开射线是开集；两个开集之交是开集；**任意**多个开集之并是开集——指标集可以是任何类型，不要求可数。

```lean
-- 开射线 (-∞, 0) 是开集
example : IsOpen {x : ℝ | x < 0} :=
  isOpen_lt continuous_id continuous_const

-- 有限交：两个开集之交仍开
example {s t : Set ℝ} (hs : IsOpen s) (ht : IsOpen t) :
    IsOpen (s ∩ t) := hs.inter ht

-- 任意并：ι 是任意类型，不要求可数
example {ι : Type} {U : ι → Set ℝ} (h : ∀ i, IsOpen (U i)) :
    IsOpen (⋃ i, U i) :=
  isOpen_iUnion h
```

三段代码，分别是开集、有限交、任意并在具体空间里的样子。注意第三行：`⋃ i, U i` 里的 `ι` 没有任何可数假设。这就是“任意并”的分量。

到这里，“开集”还只是一族子集。但观察不是孤立的：它们可以合并、可以弱化、可以互相推出。把这些关系写成代数，就遇到这篇文章真正的主角——frame。

## 二、开集的代数：frame

两个观察可以同时做（合取），一族观察可以“其中一个成立”（析取），还有一个什么都没说的观察（⊤）和一个不可能被确认的观察（⊥）。把这些操作写成代数，开集就不只是一族子集，而是一个有结构的对象。

先看序：U ⊆ V 读作“确认 U 就确认了 V”，也就是 U 蕴含 V。在这个序下：

- 任意多个开集的并仍是开集，所以任意族都有上确界，就是并。这个格是**完备**的。
- 下确界要小心：任意多个开集的交不一定是开集，所以格里的下确界是“交的内部”，不是交本身。
- 还有一条**无限分配律**：

```text
U ∩ (V₁ ∪ V₂ ∪ ⋯) = (U ∩ V₁) ∪ (U ∩ V₂) ∪ ⋯
```

对集合来说，这条律是显然的。对观察来说，它有操作性的内容：你确认了 U，又确认了“某个 Vᵢ 成立”——后者的确认必须经过某个具体的 i（你看到了一个见证）。同一次观察同时确认了 U 和那个 Vᵢ，于是也确认了 U ∩ Vᵢ。分配律说的就是：**析取的见证可以被合取复用**。

这句话是整篇文章的枢纽。它把“一族可确认的性质”升级成一个满足无限分配律的完备格，叫做 **frame**。

frame 之间的映射也由此定死：保持 ⊤、有限交、任意并。注意不要求保持蕴含——翻译不必是逻辑嵌入。

为什么偏偏是这三样？因为它们是观察逻辑的基本操作：⊤ 是空观察，∧ 是同时观察，⋁ 是“其中一个成立”（不指定是哪个）。保持它们，就是保持“什么能被确认”的结构。

```lean
-- 开集构成一个 frame：任意并、有限交，以及无限分配律
example (X : Type) [TopologicalSpace X] :
    Order.Frame (TopologicalSpace.Opens X) :=
  inferInstance
```

Vickers 的书名 *Topology via Logic* 说的就是这件事：拓扑学可以从“观察的逻辑”建立，不必从点集出发。接下来两步把这句话说实：frame 可以看作一套理论，而“点”是这套理论的模型。

## 三、否定与三态：Heyting 代数

这一节先把三态说清楚，再把它写成代数：否定、双重否定，以及为什么这里的逻辑不是布尔的。

有了开集，就能把每个点相对于一个集合 S 的位置分成三类。

- **内部** int S：所有“有一个开邻域整个落在 S 里”的点。
- **闭包** cl S：所有“每个开邻域都和 S 相交”的点。
- **边界** ∂S = cl S ∩ cl Sᶜ：两边的闭包都在。

用观察的语言读一遍，它们立刻有了意思：

| | 形式定义 | 观察读法 | 逻辑记号 |
|---|---|---|---|
| 内部 int S | 所有含于 S 的开集之并 | 已经确认 S | □S |
| 闭包 cl S | 所有包含 S 的闭集之交 | 还没有被否定 | ◇S |
| 边界 ∂S | cl S ∩ cl Sᶜ | 两边都说不清 | ◇S ∧ ◇¬S |

“已经确认”是什么意思？你手里有一个开邻域 U ∋ x，而 U ⊆ S。因为 U 是开集，它是“一次有限观察就能确认”的性质；你确认了 U，就顺带确认了 S。

“还没有被否定”更微妙：x ∈ cl S 等价于“每个开邻域都和 S 相交”。反过来说，如果存在一个开邻域完全避开 S，那你就确认了 ¬S——S 被否定了。所以闭包里的点，是那些“到目前为止，所有观察都和 S 相容”的点。

边界点是第三种状态：**两边都没结案**。x ∈ ∂S 意味着每个开邻域都同时伸进 S 和 Sᶜ，所以任何一次观察都同时相容于“x ∈ S”和“x ∉ S”。这不是“暂时倾向于某一边”，而是证据对两边都不够——S 没被确认，¬S 也没被确认。

拿 S = (0,1) ⊂ ℝ 做例子，它的边界是 {0,1}。在 x = 0 处，不管精度多高，邻域 (−ε, ε) 里总有点在 S 内、也有点在 S 外；只凭“x 离 0 有多近”，你永远判不出它在不在 S 里。内部点正相反：离 0.5 足够近就一定在 S 里；外部点也一样，离 2 足够近就一定在 S 外。

![内部、边界、外部]({{ '/images/topo-02-interior.png' | relative_url }})
{: .post-figure}

*图 2：同一个集合 S 的三种点。内部点有一个开邻域整个落在 S 里；边界点的每个开邻域都同时碰到两边；外部点有一个开邻域完全避开 S。*
{: .caption}

用 Lean 写出来，这三个定义就是三条定理：

```lean
-- x 在内部，当且仅当 S 是 x 的一个邻域
example {s : Set ℝ} {x : ℝ} :
    x ∈ interior s ↔ s ∈ 𝓝 x := mem_interior_iff_mem_nhds

-- 开区间的闭包是闭区间，边界是两个端点
example : closure (Ioo (0 : ℝ) 1) = Icc 0 1 :=
  closure_Ioo (by norm_num)
example : frontier (Ioo (0 : ℝ) 1) = {0, 1} :=
  frontier_Ioo (by norm_num)
```

不过，开集不只是一个格。它还有蕴含，而蕴含让“否定”有了确定的形状。

在 frame 里，蕴含定义为：`U → V` 是满足 `W ∩ U ⊆ V` 的最大开集 W。

它满足 residuation：`W ⊆ U → V` 当且仅当 `W ∩ U ⊆ V`。否定是它的特例：`¬U = U → ⊥`。

对开集算一下：

```text
¬U = int(Uᶜ) = (cl U)ᶜ
```

所以**否定不是补集，而是补集的内部**：你能确认“U 被否定”，当且仅当有一个开邻域整个避开 U。

于是双重否定

```text
¬¬U = int(cl U)
```

读作“U 还没有被否定”。它比 U 弱：`U ⊆ ¬¬U`，但反过来不成立。差的那部分正是边界：边界点的每个邻域都同时碰到 U 和 Uᶜ，所以既确认不了 U，也确认不了 ¬U，只能确认 ¬¬U。

```lean
-- 开集构成 Heyting 代数：有蕴含，也就有否定
example (X : Type) [TopologicalSpace X] :
    HeytingAlgebra (TopologicalSpace.Opens X) :=
  inferInstance

-- 否定 = 补集的内部
example (X : Type) [TopologicalSpace X] (U : TopologicalSpace.Opens X) :
    TopologicalSpace.Opens.interior ((U : Set X)ᶜ) = Uᶜ :=
  TopologicalSpace.Opens.interior_compl
```

这意味着**排中律在这里不成立**：`U ∪ ¬U` 一般不等于整个空间，差的就是边界。开集构成的不是布尔代数，而是 **Heyting 代数**；它对应的命题逻辑是直觉主义的（IPC），不是经典的。

这句话值得停一下：拓扑学不是“给集合加一个几何结构”，而是**换一套真值**。经典逻辑的真值是 {0, 1}；拓扑逻辑的真值是开集。一个命题的真值，是“它在哪些点上成立”这个开集；开集之间有包含、有交并、有蕴含——真值本身构成了一个格。边界点的存在，就是“既非真也非假”的真值。

![开集的格]({{ '/images/topo-02-frame.png' | relative_url }})
{: .post-figure}

*图 3：两个空间的开集格。左边 Sierpiński 空间的格只有三个元素，中间元素 P 的否定是 ∅、双重否定是 X；右边两点离散空间是布尔代数，每个元素都有补集。*
{: .caption}

现在，把表中最后一列的记号当真：令 □S = int S，◇S = cl S。它们满足的公理是：

- □S → S（确认了 S，S 当然成立）
- □S → □□S（确认了 S，就确认了“已经确认 S”）
- □(S ∧ T) ↔ □S ∧ □T（两次观察）
- S ⊆ T ⟹ □S ⊆ □T（确认了强的，就确认了弱的）
- ◇S ↔ ¬□¬S（对偶）

这套公理叫 **S4**。McKinsey 和 Tarski 在 1944 年证明：S4 恰好是所有拓扑空间的**模态**逻辑——任何一个 S4 的定理，在所有拓扑空间里都成立；任何一个非定理，都能找到一个拓扑空间作为反例。

但要注意层次：S4 是叠加在 Heyting 逻辑上的一层模态，底层的命题逻辑仍然是直觉主义的。□ 是“内部”，¬ 是“补集的内部”，两者不是一回事。

如果你写过时序逻辑，这里应该有一个强烈的既视感。上一篇里的 □（永远）和 ◇（最终），满足的也是 S4 的形状。这不是巧合，而是特例：

给定一个预序 (W, ≤)，把“上闭集”（若 w ∈ U 且 w ≤ w'，则 w' ∈ U）声明为开集，就得到一个拓扑（Alexandrov 拓扑）。在这个拓扑里，

```text
w ∈ int S  当且仅当  对所有 w' ≥ w, w' ∈ S
```

右边读作“从 w 往后，永远 S”。这正是时序逻辑的 □。于是上一篇的 □、◇ 与这里的 int、cl 是同一个东西的两种写法——区别只在底下的空间：一个是时间轴，一个是几何形状。

回到上一篇的冷知识。取空间为所有无限 0/1 序列（Cantor 空间），把“性质”看成一个序列集合 P：

- **safety**：一旦违反，就有一个有限前缀，无论后面接什么都无法挽回。用拓扑的话说，违反 P 的集合是开集——因为它被一个有限前缀确认了。所以 P 本身是**闭集**。
- **liveness**：任何有限前缀都能延伸到 P 里。用拓扑的话说，P 与每个柱体都相交，也就是 P **稠密**。

用 Heyting 的话说，这两个性质各有一句更精确的翻译：**safety 是 ¬P = Pᶜ**（否定恰好是补集，没有边界残留）；**liveness 是 ¬¬P = ⊤**（P 没有被否定的可能）。安全与活性，原来是“否定是否精确”“双重否定是否成立”这两个逻辑问题的特例。

Alpern 和 Schneider 的分解定理——“任何性质都是 safety 与 liveness 的交”——在拓扑里是一行字。对任意集合 A：

```text
A = cl A ∩ (A ∪ (X ∖ cl A))
```

cl A 是闭集（safety）。第二个因子是稠密的：任取非空开集 U，若 U 与 X ∖ cl A 相交，就已经落在因子里；否则 U ⊆ cl A，而开集与闭包相交必与 A 相交，于是 U 也与因子相交。

一个分解定理，一行集合论。这就是“换个角度看问题”能省下的东西。

## 四、点是什么：模型

到目前为止，我们默认有一个点集 X，开集是 X 的子集。现在把顺序倒过来：假设手里只有一个 frame Ω——一套可确认性质的代数，没有点。还能不能谈“点”？

能。一个点，就是**给每个观察一个真值、并且尊重逻辑**的赋值：

```text
x : Ω → {⊥, ⊤}
x(⊤) = ⊤
x(U ∧ V) = x(U) ∧ x(V)
x 保持任意并：一族观察的并若为真，则其中某个为真
```

换个说法，x 是一个 frame homomorphism `Ω → 2`，其中 2 是两元素 frame {⊥, ⊤}。关于并的那条是关键：如果“某个 Uᵢ 成立”为真，就必须有一个具体的 i 使它为真——这仍然是“见证”的要求。

这个定义有一个更熟悉的名字：**模型**。Ω 是一套理论（观察之间的关系就是公理），点是这套理论的一个模型；`x(U) = ⊤` 读作“在模型 x 里，观察 U 成立”。

于是每个观察都有**外延**：

```text
ext(U) = { x : x(U) = ⊤ }
```

这些外延构成点集上的拓扑，而且 ext 保持 frame 结构：并的外延是外延的并，交的外延是外延的交。这就是“点集上的开集”。

反过来，给定点集、frame 和满足关系 ⊩，只要满足

```text
x ⊩ 任意族的并   当且仅当   该族中某个 U 满足 x ⊩ U
x ⊩ U ∧ V        当且仅当   x ⊩ U 且 x ⊩ V
x ⊩ ⊤
```

就得到一个**拓扑系统**（topological system，Vickers 的术语）。一个拓扑空间，就是外延映射为单射的拓扑系统：每个观察都被某个点区分开。

![拓扑系统]({{ '/images/topo-03-system.png' | relative_url }})
{: .post-figure}

*图 4：拓扑系统。左：点与观察的满足关系，每一行是一个模型，每一列是一个观察；右：外延把 frame 的元素送到点集的开集，而点本身就是 frame 到 2 的同态。*
{: .caption}

这个视角的第一个回报，是 Sierpiński 空间的来历。取 Ω 为由一个生成元 P 自由生成的 frame：元素只有 ⊥、P、⊤。它的模型只有两个——P 真、P 假。两个点，开集是 ∅、{P 真}、全体——正是 Sierpiński 空间。所以 Sierpiński 空间不是人造的小反例，它是**最简单的理论的空间**：一个未知命题的两种可能。

第二个回报是实数。取 Ω 为由有理区间生成的 frame，公理说区间之间如何相容、如何覆盖；它的模型就是实数，开集就是区间的并。**实数不是预先给定的点集，而是“有理逼近”这套理论的空间。** 这是“点 = 模型”最熟悉的例子。

## 五、没有点的空间

点是派生的，这有一个直接后果：**“非空”不再等于“点非空”**。

最温和的失败是**不 sober**。例子：ℕ 配上余有限拓扑——开集是空集和补集有限的集合。它是 T1 的（每个点都是闭集），而且任意两个非空开集都相交，所以整个空间是一个“不可约闭集”。在好的空间里，不可约闭集总是一个点的闭包（那个点叫一般点）；但这里每个点的闭包就是它自己，没有任何点的闭包是整个空间。于是这个空间不是 sober 的。它的 sober 化会补上一个一般点——这个点在 frame 里一直存在，只是在原来的点集里缺席。

更彻底的是**根本没有点**。

考虑“存在一个从 ℕ 到 ℝ 的满射”这套理论。用几何逻辑写：对每个 n 和有理数 q，有一个观察“第 n 项等于 q”；公理说每项有值、值唯一、每个实数都被击中。（几何逻辑是允许有限合取、任意析取与存在量词，但不允许任意否定和蕴含的那部分逻辑——正好是 frame 能表达的部分。）这套理论在几何逻辑里是相容的，它在更大的层拓扑斯宇宙里有模型；但它在集合里没有模型——Cantor 定理说 ℕ 到 ℝ 没有满射。

于是这个 locale **非空（⊥ ≠ ⊤），却一个点也没有**。

这里的“非空”是理论的非空：它推不出矛盾。点集为空，是模型的缺席。两件事不是一回事。

对计算机科学家来说，这个区分很实在：**规范可以是相容的，但不可实现**。“这个类型有居民”与“这个规范不矛盾”不是同一件事。locale 是规范，点是实现；point-free 拓扑学研究的正是“规范本身的空间”，不管它有没有实现。

技术上，一个 locale 就是 frame 的对偶范畴里的对象：locale 的“开集”是 frame 的元素，locale 之间的映射是反过来的 frame homomorphism。sober 空间与 spatial locale 是同一回事；每个空间都有一个 sober 化。locale 还有拓扑空间一般没有的好处：它是笛卡尔闭的——函数空间总是存在；而拓扑空间的函数空间要额外假设紧生成性才存在。locale 的范畴又是 frame 的反范畴，代数的直觉可以直接搬过来。

## 六、连续是逻辑翻译

连续性的定义现在几乎是自动的。

f : X → Y 连续，等价于原像映射 f* : ΩY → ΩX 是一个 frame homomorphism——它保持任意并、有限交与 ⊤。

这不是巧合。如果 x 是 X 的一个模型（点），那么

```text
y(U) = x(f*(U))
```

给出 Y 的一个模型。**模型沿着翻译反向走**——所以映射的方向是 X → Y，而逻辑的方向是 ΩY → ΩX。原像的方向，是被“模型反变”逼出来的。

保持任意并，正是见证的要求：Y 里的观察“某个 Vᵢ 成立”翻译到 X，必须还是同一个 i 的见证。

所以：**连续映射就是理论的翻译**。空间之间的映射，是它们的观察逻辑之间的翻译；点只是翻译的副产品。这也解释了为什么连续性的定义用原像而不用像：像没有逻辑上的必然性，原像有。

在 sober 空间上，反过来也成立：每个 frame homomorphism 都来自一个连续映射。这就是为什么 locale 可以当作空间的替代品——在好的空间上，两种语言说的是同一件事。

```lean
-- 原像保持任意并、有限交：这正是 frame homomorphism 的条件
example {X Y : Type} [TopologicalSpace X] [TopologicalSpace Y]
    (f : X → Y) {ι : Type} (U : ι → Set Y) :
    f ⁻¹' (⋃ i, U i) = ⋃ i, f ⁻¹' U i := by
  ext x; simp

example {X Y : Type} [TopologicalSpace X] [TopologicalSpace Y]
    (f : X → Y) (U V : Set Y) :
    f ⁻¹' (U ∩ V) = f ⁻¹' U ∩ f ⁻¹' V := by
  ext x; simp
```

回到定义本身：f : X → Y 连续，当且仅当 **Y 里每个开集的原像，都是 X 里的开集**。

```text
f 连续   当且仅当   对每个开集 U ⊆ Y，f⁻¹(U) 也是开集
```

为什么是这个定义？因为它说的正是“输出的观察可以被输入回答”：

- 你想确认“f(x) ∈ U”，这是一个关于输出的观察。
- 这个观察等价于“x ∈ f⁻¹(U)”，一个关于输入的断言。
- 连续性保证后者是开集，也就是“一次有限观察就能确认”。

所以连续映射是**信息不放大**的映射：它不会把一个需要无限信息才能确认的输出，变成一个需要无限信息才能确认的输入。反过来，如果某个 f⁻¹(U) 不是开集，那么存在一个点，你必须看完无限多位才能知道它的像在不在 U 里——这个函数在某处“放大”了信息。

![连续映射与开集原像]({{ '/images/topo-03-continuous.png' | relative_url }})
{: .post-figure}

*图 5：U 是 Y 里的一个观察；它的原像是 X 里“能被有限观察确认”的集合。连续性的内容就是：每个 U 的原像都必须是开集。*
{: .caption}

在度量空间里，这个定义退化成熟悉的 ε-δ。两个方向各一句话：

- 若 f 连续，取 ε > 0。球 B(f(x), ε) 是开集，它的原像是开集且包含 x，所以包含某个球 B(x, δ)。
- 反之，若 ε-δ 成立，取开集 U 和 x ∈ f⁻¹(U)。存在 ε 使 B(f(x),ε) ⊆ U；对应的 δ 给出 B(x,δ) ⊆ f⁻¹(U)。于是 f⁻¹(U) 是若干球的并，开。

Lean 里这两个定义是同一件事的两条定理：

```lean
-- 连续，当且仅当每个开集的原像开
example {f : ℝ → ℝ} :
    Continuous f ↔
      ∀ s : Set ℝ, IsOpen s → IsOpen (f ⁻¹' s) :=
  continuous_def

-- 同一个定义的 ε-δ 形式
example {f : ℝ → ℝ} :
    Continuous f ↔
      ∀ x, ∀ ε > 0, ∃ δ > 0, ∀ y,
        dist y x < δ → dist (f y) (f x) < ε :=
  Metric.continuous_iff
```

不连续长什么样？看阶梯函数：x < 0 时取 0，否则取 1。它在 0 处“跳”了一下。用开集的语言，这个跳变有一个精确的证据：取 U = (1/2, ∞)，它是开集；它的原像是 [0, ∞)，不是开集——因为 0 在里头，但 0 的任何开邻域都包含负数，而负数被映到 0，不在 U 里。

```lean
-- 不连续的证据：一个开集，它的原像不是开集
example : ¬ Continuous (fun x : ℝ =>
    if x < 0 then (0 : ℝ) else 1) := by
  let f : ℝ → ℝ := fun x => if x < 0 then (0 : ℝ) else 1
  change ¬ Continuous f
  intro h
  have hopen : IsOpen (f ⁻¹' Ioi (1 / 2)) :=
    h.isOpen_preimage _ isOpen_Ioi
  have hset : f ⁻¹' Ioi (1 / 2) = Ici 0 := by
    ext x
    by_cases hx : x < 0
    · simp [f, hx, not_le.mpr hx]
    · have hx' : (0 : ℝ) ≤ x := not_lt.mp hx
      simp [f, hx, hx']
      norm_num
  rw [hset] at hopen
  obtain ⟨ε, hε, hball⟩ := Metric.isOpen_iff.mp hopen 0 (by simp)
  have hmem : (-(ε / 2) : ℝ) ∈ Metric.ball (0 : ℝ) ε := by
    rw [Metric.mem_ball, Real.dist_eq, abs_lt]
    constructor <;> linarith
  have hneg : (-(ε / 2) : ℝ) ∈ Ici (0 : ℝ) := hball hmem
  simp at hneg
  linarith
```

这段代码值得读完：它没有用“极限不存在”这种说法，而是**构造了一个开集作为反例**。这正是拓扑证明的典型形状——不连续不是一个模糊的直觉，而是一个具体的开集，它的原像不够开。

还有一件小事，但很说明问题：连续性的定义用的是**原像**，不是像。连续映射的像不必是开集（常数映射把开集映成一个点）。把“开集的原像开”换成“开集的像是开”，得到的是另一类映射（开映射），它们和连续映射互不包含。这个不对称，来自“观察”的方向：我们是从输出倒推输入。

最后一个漂亮的刻画，留作练习：Sierpiński 空间 𝕊 只有两个点 0、1，开集是 ∅、{1}、{0,1}。那么，“X 的开集”与“连续映射 X → 𝕊”一一对应：开集 U 对应特征函数 χ_U（U 里取 1，外面取 0），而 χ_U 连续当且仅当 U 开。换句话说，**开集就是用 Sierpiński 值“半判定”出来的性质**。χ_U(x) = 1 是一个可以确认的答案；χ_U(x) = 0 不是。

## 七、同胚：形状就是可逆的连续

两个空间“形状一样”，最自然的定义是：存在一个双射，两个方向都连续。这叫**同胚**（homeomorphism），记作 X ≅ Y。

同胚是拓扑学里的“同构”。和群同构、类型同构一样，它要求双向：只有一边连续不够。

一个反例说明为什么：f : [0,1) → S¹，t ↦ exp(2πit)。它是连续双射——绕一圈，每个点恰好被访问一次。但它的逆不连续：t → 1 时，f(t) 绕回起点附近，而逆映射在起点附近会把两个“不同方向”的点送到相距很远的地方。于是 [0,1) 与 S¹ 不同胚。**双射不是同构**，这条在代数里你早就知道，在拓扑里它同样致命。

怎么证明两个空间**不**同胚？找一个同胚保持的性质，也就是**不变量**，然后证明一边有一边没有。常用的不变量：

| 不变量 | 一句话 | 例子 |
|---|---|---|
| 紧致性 | 开覆盖有有限子覆盖 | [0,1] 有，ℝ 没有 |
| 连通性 | 不能切成两个非空开集 | ℝ 有，{0,1} 没有 |
| 道路连通性 | 任意两点有道路相连 | S¹ 有，拓扑学家的正弦曲线没有 |
| 基本群 π₁ | 环路模同伦 | S¹ 是 ℤ，ℝ² 是 0 |
| Hausdorff | 任意两点可被开集分开 | ℝ 有，双原点直线没有 |

用紧致性证明 [0,1] 与 ℝ 不同胚，短得可以完整写出来：

```lean
-- 紧致性是拓扑不变量：同胚把紧空间搬到紧空间
theorem interval_not_homeo_real :
    ¬ Nonempty (Icc (0 : ℝ) 1 ≃ₜ ℝ) := by
  rintro ⟨e⟩
  haveI : CompactSpace ↥(Icc (0 : ℝ) 1) :=
    isCompact_iff_compactSpace.mp isCompact_Icc
  haveI : CompactSpace ℝ := e.compactSpace
  exact NoncompactSpace.noncompact_univ
    (isCompact_univ : IsCompact (univ : Set ℝ))
```

读法：假设有同胚 e。[0,1] 紧致，同胚保持紧致性，所以 ℝ 也紧致；但 ℝ 不紧致，矛盾。

顺便拆掉一个直觉陷阱：ℝ 和 (0,1) **是同胚的**。映射 x ↦ 1/2 + arctan(x)/π 把整条直线压进 (0,1)，逆映射 y ↦ tan(π(y − 1/2)) 连续。“有界”不是拓扑性质，“能不能跑到无穷远”才是——而跑到无穷远这件事，在 (0,1) 里表现为跑到端点，端点被拿掉了，所以它和直线一样“没有尽头”。

## 八、紧致：有限次观察就够

紧致性的标准定义是：**任意开覆盖都有有限子覆盖**。

第一次看到这个定义，多数人会觉得它莫名其妙。用观察的语言读一遍就顺了：开覆盖是“在每个点附近都有一份局部证书”；有限子覆盖是“只用有限多份证书，就覆盖了全局”。所以紧致性是**把局部性质升级成全局性质时，账单仍然有限**的保证。

用逻辑的话说：如果一族观察的并是 ⊤（每个模型都至少满足其中一个），紧致性保证有限个就够。“在所有模型上都成立”这件事，可以由有限个案例见证。

最典型的例子是极值定理：闭区间上的连续函数一定取到最大值。先看结论的两半：连续像 f([0,1]) 是紧集；ℝ 里的紧集有界且闭，所以上确界 M = sup f([0,1]) 存在，而且落在 f([0,1]) 里——M 被取到。

第二半可以用反证写得更直白：如果对每个 x 都有 f(x) < M，那么对每个 n，开集 {x : f(x) < M - 1/n} 覆盖 [0,1]。紧致性给出有限子覆盖，于是存在一个 N，使得所有 x 都满足 f(x) < M - 1/N——这与 M 是上确界矛盾。

注意紧致性在这里干了什么：它把“每个点都能再逼近一点”这种**逐点**的说法，变成了“存在一个统一的 N”这种**有限**的说法。

```lean
-- [0,1] 紧致
example : IsCompact (Icc (0 : ℝ) 1) := isCompact_Icc

-- 连续函数在紧集上取到最大值
example (f : ℝ → ℝ) (hf : Continuous f) :
    ∃ x ∈ Icc (0 : ℝ) 1, ∀ y ∈ Icc 0 1, f y ≤ f x := by
  have hne : (f '' Icc (0 : ℝ) 1).Nonempty :=
    ⟨f 0, Set.mem_image_of_mem f
      (by norm_num : (0 : ℝ) ∈ Icc 0 1)⟩
  obtain ⟨m, ⟨x, hx, rfl⟩, hmax⟩ :=
    (isCompact_Icc.image hf).exists_isLUB hne
  exact ⟨x, hx, fun y hy => hmax.1 (Set.mem_image_of_mem f hy)⟩
```

同一个机制还给出**一致连续**（Heine–Cantor）：紧集上的连续函数，δ 可以不依赖 x。证明只用一句话：对每个 x 取一个 δ(x)，这些球覆盖全空间，紧致性给出有限个，取其中最小的 δ。逐点的 δ 被压成了一个统一的 δ。

![紧致与不紧致]({{ '/images/topo-05-compact.png' | relative_url }})
{: .post-figure}

*图 7：左：[0,1] 的任意开覆盖都能抽出有限个。右：(0,1) 上的一族开集 Uₙ = (0, 1-1/n)，每个都差一点到 1，任何有限个都盖不住。*
{: .caption}

几个必须记住的反例：

- (0,1) 不紧致：上面那族 Uₙ 就是证据。
- ℚ ∩ [0,1] 在 ℚ 里是闭且有界的，但不紧致——因为它有“洞”。这说明 Heine–Borel（在 ℝⁿ 里紧致 ⟺ 有界且闭）依赖完备性，不是随便一个度量空间都成立。
- 无限维的单位球不紧致。紧致性是很强的要求。

最后提一句 Tychonoff 定理：任意多个紧空间的乘积仍然紧致（等价于选择公理）。所以 [0,1] × [0,1] × ⋯ 这种无限乘积也是紧的。对计算机科学家来说，它的意思是：即使状态空间是无限维的，“有限子覆盖”这件事仍然成立——只要每个维度各自紧。

## 九、连通：不能切成两半

连通性的定义：不能写成两个不相交的非空开集之并。

这个定义有一个对计算机科学家更友好的等价形式：**每个连续映射 X → {0,1}（右边取离散拓扑）都是常函数。**

也就是说，连通的意思是：你找不到一个非平凡的、连续的 Bool 值判定器。任何试图把空间“二分类”的连续程序，都只能给出一个答案。

用 frame 的话说，clopen 就是**可判定的命题**：`U ∨ ¬U = ⊤` 且 `U ∧ ¬U = ⊥`。连通就是：理论里没有非平凡的判定命题——你找不到一个观察，能把空间干净利落地分成两半。

为什么等价？如果 X = A ∪ B 是两个非空开集的不交并，那么“在 A 里取 0、在 B 里取 1”就是一个连续映射，且不是常函数。反过来，一个非常函数的连续 {0,1} 值映射，把原像分成两个非空开集。

ℝ 连通；区间连通；S¹ 连通。ℚ 不连通：在 ℚ 里，(-∞, √2) 和 (√2, ∞) 都是开集，它们把 ℚ 切成两半；Cantor 空间也不连通（每个柱体都是既开又闭的）。

连通性最重要的推论是**介值定理**：连续映射把连通集映成连通集。对 f : [a,b] → ℝ，如果 f(a) < y < f(b)，那么一定存在 c ∈ (a,b) 使 f(c) = y。

```lean
-- 区间连通
example : IsPreconnected (Icc (0 : ℝ) 1) := isPreconnected_Icc

-- 介值定理：f 在 [a,b] 上的像覆盖 f(a) 与 f(b) 之间的一切
example (f : ℝ → ℝ) (hf : Continuous f) {a b : ℝ} (hab : a ≤ b) :
    Icc (f a) (f b) ⊆ f '' Icc a b :=
  intermediate_value_Icc hab hf.continuousOn
```

连通但不路径连通的空间是存在的，最著名的是**拓扑学家的正弦曲线**：y = sin(1/x)（x > 0）的图像，加上 x = 0 处从 -1 到 1 的那条竖线。整条曲线连通，但从竖线上的点出发，你没法沿着曲线走到右边——路必须穿过无限次振荡。

对工程师来说，连通性有一个非常具体的版本：**配置空间的连通分支，就是机器人（或协议状态）在连续参数下能够互相到达的区域。** 机械臂从姿态 A 移到姿态 B，如果配置空间不连通，那么无论规划算法多聪明都做不到——这不是算法问题，是拓扑问题。同样，“系统的安全状态集合是否连通”决定了你能不能在不越过危险区的前提下连续地调参。

## 十、商空间：把点粘起来

到目前为止，我们一直在“看”已有的空间。商空间是**造**空间的方法：声明一些点等价，然后让它们变成同一个点。

形式化地，给定集合 X 和一个等价关系 ~，商集 X/~ 的元素是等价类。投影 q : X → X/~ 把每个点送到它的类。现在给商集配一个拓扑：**让 q 连续的最细的拓扑**。

“最细”是什么意思？开集越多拓扑越细。q 连续要求“每个开集的原像开”，这本身定义了商集上的一族开集：U 开 ⟺ q⁻¹(U) 开。它是满足这个条件的最大的一族——再加就破坏 q 的连续性了。

这个“最细”的选择有一个漂亮的后果，叫**泛性质**：

```text
g : X/~ → Z 连续   当且仅当   g ∘ q : X → Z 连续
```

要证明一个从商空间出发的函数连续，你只需要看它和投影的复合。这正是商类型的消去规则：要定义从 `Quotient s` 出发的函数，你先在代表元上定义，再证明它与等价关系相容；连续性也一样，先在 X 上验证，商空间自动继承。

用 frame 的话说更清楚：商映射 q 的原像 q* : ΩQ → ΩX 是单射（因为 q 满射），所以**商空间的观察是 X 的观察的一个子代数**。识别点，等于加强理论——能确认的性质变少了，能区分的点也变少了。

三个标准例子：

- **圆**：[0,1] 把 0 和 1 粘起来，得到 S¹。等价的写法是 ℝ/ℤ：实数模整数。
- **环面**：正方形的对边分别粘起来，得到 T² = S¹ × S¹。
- **Möbius 带**：矩形的一边翻转后再粘，得到只有一个面、一条边的曲面。

![商空间]({{ '/images/topo-07-quotient.png' | relative_url }})
{: .post-figure}

*图 9：三种粘合。粘合方式（边的方向）决定了得到的空间；同一个正方形，换个粘法就是另一个曲面。*
{: .caption}

Lean 里，商类型就是 `Quotient`，配上一个 `Setoid`（带等价性证明的等价关系）：

```lean
/-- x ~ y：差是整数 -/
def modInt (x y : ℝ) : Prop := ∃ k : ℤ, y = x + k

def modIntSetoid : Setoid ℝ where
  r := modInt
  iseqv := by
    refine ⟨?_, ?_, ?_⟩
    · intro x
      exact ⟨0, by simp⟩
    · rintro x y ⟨k, hk⟩
      exact ⟨-k, by push_cast [hk]; linarith⟩
    · rintro x y z ⟨k, hk⟩ ⟨l, hl⟩
      exact ⟨k + l, by push_cast [hk, hl]; linarith⟩

/-- 圆 = ℝ / ℤ -/
abbrev CircleMod := Quotient modIntSetoid

-- 投影自动连续
example : Continuous
    (Quotient.mk modIntSetoid : ℝ → CircleMod) :=
  continuous_quotient_mk' (s := modIntSetoid)

-- 而且它是商映射：判断“从圆出发的函数连续”，只需看复合
example : Topology.IsQuotientMap
    (Quotient.mk modIntSetoid : ℝ → CircleMod) :=
  isQuotientMap_quotient_mk' (s := modIntSetoid)
```

这段代码值得对照上面的定义读：`modIntSetoid` 就是等价关系，`Quotient` 就是商集，`continuous_quotient_mk'` 说的是“投影连续”，`isQuotientMap_quotient_mk'` 说的是“它就是商映射”——这两条合起来，就是泛性质的一半；另一半（从商空间出发的映射连续）由 `Topology.IsQuotientMap` 的 API 提供。

商空间有一个必须警惕的地方：**它可能不 Hausdorff**。最著名的例子是“双原点直线”：取两条实数轴，把除 0 以外的所有点对应粘起来，得到一条有两个原点的直线。两个原点无法被开集分开。商操作可以识别点，也就可以破坏分离性。

另一个坑：**商映射不一定是开映射**。取 Sierpiński 空间（开集 ∅、{1}、{0,1}），把两个点粘成一个，得到的商空间是平凡拓扑；投影把开集 {1} 映成一个点，而那个点在商空间里不是开集。为什么？因为商拓扑是“让投影连续”的最细拓扑，不是“让投影开”的拓扑。这两件事不一样。

这也是为什么“商”在工程上要小心：它把等价关系变成类型，同时也把拓扑变粗了。你抽象掉的信息，可能正是别人需要的观察。

## 十一、同伦：允许形变之后

同胚比你想的松：[0,1] 和 [0,2] 是同胚的（x ↦ 2x），尽管长度不同——长度不是拓扑性质。但它又比你想的紧：S¹ 和 ℝ² ∖ {0} 不同胚，虽然后者可以“缩”成前者。

拓扑学于是引入一个更粗的等价：**同伦**。

两个连续映射 f, g : X → Y 同伦，如果存在一个连续映射

```text
H : X × [0,1] → Y，  H(x,0) = f(x)，  H(x,1) = g(x)
```

[0,1] 是“时间”参数：H 是一段连续的形变，从 f 变到 g。

如果两个空间之间存在同伦互逆的映射（f ∘ g 同伦于恒等，g ∘ f 同伦于恒等），就说它们**同伦等价**。同伦等价比同胚粗：ℝ² ∖ {0} 同伦等价于 S¹（沿着射线缩过去），但它们不同胚（一个开，一个紧）。

```lean
-- 同伦就是一个连续映射 [0,1] × X → Y
def lineHomotopy (f g : C(ℝ, ℝ)) :
    ContinuousMap.Homotopy f g where
  toFun p := (1 - (p.1 : ℝ)) * f p.2 + (p.1 : ℝ) * g p.2
  continuous_toFun := by fun_prop
  map_zero_left x := by simp
  map_one_left x := by simp

-- 于是 ℝ 上任意两个连续映射都同伦：ℝ 是可缩的
example (f g : C(ℝ, ℝ)) :
    ContinuousMap.Homotopic f g := ⟨lineHomotopy f g⟩
```

`lineHomotopy` 就是“直线形变”：在时刻 t，把每个点按比例 (1-t) 和 t 混合。`fun_prop` 一行证明它连续；两个端点条件由 `simp` 关掉。最后一行说明：在 ℝ 里，任何两个映射都能互相形变——因为 ℝ 可以缩成一个点。

**可缩**（contractible）的空间，就是同伦等价于一个点的空间。ℝⁿ、任何凸集、任何“星形”区域都可缩。可缩空间里没有洞。

## 十二、洞是算出来的：基本群

同伦等价允许我们把空间压扁，但有一件事压不掉：**洞**。

把洞变成代数的方法，是基本群。取一个基点 x₀ ∈ X，考虑所有从 x₀ 出发又回到 x₀ 的环路。两条环路可以首尾相接，也可以反向走，于是它们构成一个群——但要把“可以连续形变”的环路视为同一个元素：

```text
π₁(X, x₀) = { 基于 x₀ 的环路 } / （保端点的同伦）
```

群的运算就是“先走第一条，再走第二条”；单位元是停在原地；逆元是反向走。

π₁(S¹) ≅ ℤ。每个环路对应一个整数：绕了多少圈，逆时针为正。这个整数叫**绕数**（winding number），它在连续形变下不变——你没法把绕一圈的环路缩成一个点，因为要缩，就得让环路穿过那个洞。

π₁(ℝ² ∖ {0}) ≅ ℤ，而 π₁(ℝ²) = 0。于是这两个空间不同胚：一个有洞，一个没有。

![绕数与基本群]({{ '/images/topo-08-homotopy.png' | relative_url }})
{: .post-figure}

*图 10：挖了一个点的平面。绕数 1 的环路缩不成一点；绕数 0 的环路可以缩成一个点。基本群把这个“缩不缩得动”变成一个整数。*
{: .caption}

基本群最重要的性质是**函子性**：每个连续映射 f : X → Y 诱导一个群同态

```text
f∗ : π₁(X, x₀) → π₁(Y, f(x₀))
```

而且同伦的映射诱导同一个同态。所以同胚诱导同构——π₁ 是不变量。这就是为什么可以用代数去证明“两个空间不同胚”。

Lean 里，基本群定义在基本群胚的自同态群上：

```lean
-- 基本群：以 x 为基点的环路，模掉保端点的同伦
noncomputable example (X : Type) [TopologicalSpace X] (x : X) :
    Group (FundamentalGroup X x) :=
  inferInstance

-- 连续映射诱导群同态；同伦的映射诱导同一个同态
#check @FundamentalGroup.map
```

这个“洞”的论证有一个著名的应用：**Brouwer 不动点定理**。任何连续映射 f : D² → D² 都有不动点。证明是反证：如果没有不动点，从 f(x) 出发经过 x 作射线，交边界于 r(x)，就得到一个连续收缩 r : D² → S¹（r 在边界上是恒等）。但这样的收缩不存在。设 i : S¹ → D² 是包含映射，收缩条件 r ∘ i = id 会诱导 r∗ ∘ i∗ = id_ℤ。可是 π₁(D²) = 0，所以 i∗ 只能是零同态，r∗ ∘ i∗ 也只能是零同态——零同态不可能是 ℤ 上的恒等。

一个关于“连续函数必有不动点”的定理，最后是用“洞不能被填平”证明的。这就是代数拓扑的力量：把几何问题翻译成代数问题，再翻译回来。

## 十三、为什么计算机科学家该在乎

前面十二节都在讲数学。这一节说说它和你的日常工作有什么关系。不是“学了有好处”这种话，而是几个具体的接口。

如果只带走一个可迁移的观念，那就是：**类型与规范是理论，值是模型，可观察性质是开集**。这不是类比——拓扑系统就是这三件事的公理化；下面五条都是它的特例。

**1. 域论与程序语义：开集就是可观察性质。**

Scott 在 1972 年给程序语义配了一个拓扑：在一个“信息域”上，开集恰好是“有限信息就能确认”的性质；Scott 连续函数恰好是保持有向上确界的函数；在可有效给出的域上，这正是可计算的函数。在这个拓扑里，“程序在输入 n 上停机”是一个开集——停机问题的半可判定性，就是它的开性。你写的每一个“可能不终止”的函数，在域论里都是一个偏序集里的点；它的 Scott 拓扑，记录了你对它究竟能知道什么。

**2. 可计算分析：连续 = 可计算。**

在表示空间（represented space）的理论里，一个函数是可计算的，当且仅当它是（关于合适表示的）连续的。这不是类比，是定理：Type-Two Effectivity 的主定理。它给“连续”一个操作性的解释——连续就是“存在一个只用有限信息就能工作的算法”。反过来说，不连续的地方，就是任何算法都必须“看完无限多位才能决定”的地方。

**3. 分布式计算：协议复形的拓扑。**

Herlihy 和 Shavit 在 1999 年证明：一个分布式任务是否 wait-free 可解，取决于协议复形的拓扑性质（连通性、无环性）。FLP 不可能性也有拓扑证明：把可能的执行看成复形，“所有进程最终都要做决定”变成一个拓扑障碍。这个方向叫**分布式计算的拓扑方法**，它把“共识能不能做”变成“某个复形有没有洞”。

**4. 拓扑数据分析：数据的洞。**

给定一团点云，怎么知道它有没有“洞”？持续同调（persistent homology）在不同尺度上计算洞的出现与消失，并给出一个稳定性定理：数据扰动一点点，结果只变一点点。这是把拓扑不变量变成统计量的标准做法。

**5. 同伦类型论：类型就是空间。**

在 HoTT 里，类型被解释成空间，项是点，相等证明是路径，路径之间的同伦是高阶路径。S¹ 可以作为一个高阶归纳类型定义：一个点 `base`，一条路径 `loop : base = base`。univalence 公理说“等价即相等”。这套语言让“商”“粘合”“洞”都变成了类型论里的构造。

需要诚实地说一句：Lean 4 + mathlib 不是 HoTT。它建立在经典集合论的基础上（有排中律、选择公理、证明无关性），`Quot` 给出的是集合层面的商，没有路径构造子。要在 proof assistant 里做 HoTT，得用 Cubical Agda 或 HoTT-Coq。但本文用到的所有东西——开集、连续、紧致、连通、商、同伦、基本群——在 Lean 4 里都是可以定义、可以证明的。

## 十四、带走一张地图

把全文压缩成一张对照表：

| 你熟悉的东西 | 拓扑里的名字 | 一句话 |
|---|---|---|
| 半可判定 | 开集 | 有限步能确认 |
| 观察的代数（理论） | frame | 有限交、任意并、无限分配律 |
| 模型 / 实现 | 点 | 尊重逻辑的真值分配 |
| 翻译 | 连续映射 | 原像保持交与并 |
| 已确认 / 未否定 / 说不清 | 内部 / 闭包 / 边界 | 三种认知状态 |
| 有限步能否定 | 闭集 | 补集是开集 |
| 可判定的命题 | clopen | U ∨ ¬U = ⊤ |
| 有限证书 | 紧致 | 开覆盖有有限子覆盖 |
| 没有非平凡的连续 Bool | 连通 | 不能切成两块 |
| 数据抽象 | 商空间 | 等价类 + 最细的商拓扑 |
| 可以忽略的实现细节 | 同伦 | 连续形变 |
| 绕不过去的洞 | 基本群 | 绕数 |

如果只带走五句话：

1. **拓扑是一族“可确认的性质”，它们的代数是一个 frame。** 点是派生的：一个点就是给每个观察一个尊重交与并的真值——也就是这套理论的一个模型。
2. **否定是补集的内部：¬U = int Uᶜ，¬¬U = int cl U。** 排中律在边界上失效，所以开集的逻辑是 Heyting 代数，不是布尔代数。
3. **连续是理论的翻译。** 原像保持交与并，方向是反的，因为模型沿着翻译反向走。
4. **紧致是“有限见证”，连通是“没有非平凡的判定命题”。** 一个关于有限性，一个关于整体性。
5. **形状是同胚类，洞是基本群；而“非空”不等于“有点”。** 规范可以相容却不可实现，locale 让这件事有了精确的说法。

回到开头的问题：两个东西“形状一样”是什么意思？

拓扑学的回答是：存在一个双向连续的双射。但这个回答之所以有意义，是因为“连续”已经被翻译成了“观察”：形状不是画出来的，是**在有限观察下保持不变的东西**。

这也解释了为什么拓扑学会出现在那么多意想不到的地方。程序语义、分布式协议的可行性、数据里有没有洞、类型相不相等——它们表面上都在问“这个东西是什么形状”，实际上都在问同一个问题：

**在一个只能做有限观察的世界里，什么是不变量？**

拓扑学就是这个问题的一种系统回答。而 Lean 这样的工具，让这个回答可以被机器检查——从“我觉得这个证明对”变成“内核接受了这个证明”。
